# Omid Rahimi Engineering Portfolio

A bilingual React and Vite portfolio for Omid Rahimi, focused on Wireless/RF,
RAN, communication systems, integration, validation, and technical automation.

## Local development

```sh
npm install
npm run dev
```

## Quality checks

```sh
npm run lint
npm test
npm run build
```

The production site is deployed through Netlify. The contact form uses Netlify
Forms, and the English and German CV files are served from `public/files`.
